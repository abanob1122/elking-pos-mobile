# ELKing POS — تطبيق الموبايل لصاحب المحل (Progressive Web App)

تطبيق ويب تقدمي (PWA) حديث، سريع، ومتكامل وموجّه لصاحب المحل والمديرين، يتيح متابعة المبيعات الحية، الورديات، الخزينة، المخزون، وإدارة الموظفين مباشرة عبر السحابة بالاتصال الفعلي بقاعدة بيانات Supabase، مع دعم التثبيت المباشر على شاشة الهواتف الذكية (Android & iPhone).

---

## 🌟 المميزات الرئيسية

1. **لوحة معلومات ومؤشرات حية (Live Dashboard):**
   - فلترة لحظية حسب الفرع ("جميع الفروع" أو فرع محدد).
   - إجمالي مبيعات اليوم وعدد الفواتير المكتملة.
   - نقدية الدرج الحقيقية (كاش) بعد خصم المصروفات.
   - مبيعات البطاقات الإلكترونية والمحافظ (فيزا / انستاباي).
   - متابعة الورديات المفتوحة حالياً في كافة الفروع ومبيعات كل وردية واسم الكاشير.
   - تنبيهات فورية لنواقص المخزون التي أوشكت على النفاد.

2. **سجل الفواتير والمبيعات (Sales & Invoices):**
   - استعراض أحدث الفواتير مع تصنيف طرق الدفع بالألوان.
   - بحث فوري برقم الفاتورة أو اسم العميل أو الهاتف، وفلترة حسب التاريخ وطريقة السداد.
   - نافذة تفصيلية لكل فاتورة تعرض جدول الأصناف، الأسعار، الخصومات، والمدفوع.

3. **إدارة المخزون والأسعار (Inventory):**
   - بحث سريع بالاسم أو الباركود الدولي (`barcode_ean13`).
   - فلتر سريع لعرض "النواقص فقط".
   - إمكانية تعديل سعر البيع (`sale_price`) وحد الطلب (`min_stock`) مباشرة من الموبايل وتحديثه فورياً في السحابة وأجهزة الكاشير.

4. **الخزينة والورديات (Treasury & Shifts):**
   - متابعة حركات الخزينة والمصروفات والإيداعات مع بيان السبب والمستخدم.
   - استعراض سجل الورديات المغلقة والجارية ومطابقة النقدية مع العجز أو الزيادة.

5. **إدارة الموظفين ثنائية الاتجاه (Staff Management):**
   - إضافة موظف جديد وتحديد فرعه ودوره وصلاحياته.
   - **تشفير متطابق 100% مع البرنامج المكتبي:** يستخدم خوارزمية `PBKDF2-HMAC-SHA256` مع 200,000 دورة وتوليد ملح عشوائي 16 بايت، مما يتيح للموظف الجديد تسجيل الدخول فوراً على جهاز الكاشير المكتبي دون أي تعارض!
   - زر التفعيل السريع: إيقاف موظف أو إعادة تفعيله بنقرة واحدة، مع تطبيق الأثر اللحظي على الكاشير.
   - إمكانية تغيير كلمة مرور أي موظف أو حذفه بأمان.

6. **الربط السريع الذكي عبر QR Code (Smart Onboarding):**
   - يدعم التطبيق استقبال معرّف المتجر واسم المتجر عبر معاملات الرابط (`?store_id=...&store_name=...`).
   - بمجرد مسح رمز الـ QR Code من شاشة البرنامج المكتبي، يتم حفظ بيانات المتجر فورياً في التطبيق وتنظيف الرابط، مع عرض شارة المتجر والتركيز مباشرة على تسجيل الدخول.

7. **مواصفات PWA المتطورة:**
   - واجهة عربية بالكامل (`dir="rtl"`) مع خط Cairo الأنيق.
   - دعم الوضع الليلي (Dark Mode) والنهاري التلقائي.
   - دعم التثبيت المباشر كأيقونة تطبيق على الشاشة الرئيسية (Add to Home Screen).
   - شيل تطبيق يعمل دون اتصال (Offline Shell) عبر `service-worker.js`.

## 🚀 طريقة التشغيل المحلي (Local Testing)

لا تحتاج إلى تثبيت أي حزم برمجية معقدة؛ التطبيق يعمل كـ Static PWA مستقل:

1. افتح منفذ الأوامر (Terminal أو PowerShell) في مجلد المشروع:
   ```bash
   cd mobile_pwa
   python -m http.server 8080
   ```
2. افتح المتصفح على جهاز الكمبيوتر:
   ```
   http://localhost:8080
   ```
3. **لفتحه وتجربته على هاتفك المحمول المتصل بنفس شبكة الـ Wi-Fi:**
   - اعرف عنوان الـ IP المحلي لجهاز الكمبيوتر (عبر كتابة `ipconfig` في الويندوز، مثل: `192.168.1.5`).
   - افتح متصفح الموبايل (Chrome أو Safari) واكتب:
     ```
     http://192.168.1.5:8080
     ```

## 🌐 خطوات النشر المجاني على مدار الساعة (Free Deployment)

لكي يعمل التطبيق عبر رابط إنترنت دائم وآمن (`https://`) يمكنك استخدامه من أي مكان في العالم وتثبيته كتطبيق حقيقي:

### الخيار 1: Vercel (في دقيقة واحدة — موصى به)
1. سجّل دخولك مجاناً على [Vercel.com](https://vercel.com) عبر حساب GitHub.
2. ثبت أداة Vercel CLI (اختياري) أو ارفع المجلد:
   ```bash
   cd mobile_pwa
   npx vercel deploy --prod
   ```
3. أو اسحب مستودع Git إلى Vercel وحدد `Root Directory` كـ `mobile_pwa`.
4. ستحصل فوراً على رابط HTTPS مجاني مثل `https://elking-pos.vercel.app`.

### الخيار 2: Netlify (بدون أوامر — سحب وإفلات)
1. افتح [Netlify.com](https://www.netlify.com).
2. من لوحة التحكم، اذهب إلى قسم **Sites** ثم اسحب مجلد `mobile_pwa` وأفلته في المربع المخصص (Drop folder to deploy).
3. سينشر موقعك في ثوانٍ برابط دائم ومجاني.

### الخيار 3: GitHub Pages
1. ادفع المشروع إلى مستودع GitHub.
2. من إعدادات المستودع (Settings ➔ Pages)، اختر الفرع ومجلد `mobile_pwa`.
3. سيعمل التطبيق مجاناً ومباشرة.

## 📱 خطوات التثبيت على الهاتف (Add to Home Screen)

- **على هواتف Android (Chrome):**
  - افتح رابط التطبيق في متصفح Chrome.
  - ستظهر رسالة أسفل الشاشة "إضافة ELKing POS إلى الشاشة الرئيسية" (أو اضغط على الثلاث نقاط ➔ "تثبيت التطبيق").
- **على هواتف iPhone (Safari):**
  - افتح رابط التطبيق في متصفح Safari.
  - اضغط على زر المشاركة (مربع بسهم للأعلى).
  - اختر "إضافة إلى الصفحة الرئيسية" (Add to Home Screen).

## 🔒 الأمان وحسابات تسجيل الدخول

- التطبيق مخصص لإدارة المتجر، ويسجل الدخول باستخدام بيانات حسابات الإدارة (`Admin` أو `Manager`) المسجلة في جدول `staff_users`.
- يتم التحقق من كلمات المرور محلياً على جهاز الموبايل عبر Web Crypto API بمطابقة الهاش المشفر، دون إرسال كلمة المرور الصريحة عبر الشبكة.
